IMPORTANT PUBLIC PATH NOTE

The JSON may contain paths like:

/public/assets/episode-29/audio/music/friends-theme.mp3

But in most frontend frameworks, assets inside /public are referenced in the browser as:

/assets/episode-29/audio/music/friends-theme.mp3

Please create a small helper function to normalise asset paths, for example:

function publicUrl(path) {
  return path.replace(/^\/public/, "");
}

Use this helper for all images/audio/video paths so the site works whether the JSON path starts with /public or not.
